## Entry

`main.py` (Python standard library only) writes the fortune to `/output/entry.txt`:

> Soon a guest will beg for a cutting, and you will become a grandparent without ever leaving this sill.

(102 characters, one line.)

## Run locally

```sh
python3 main.py
cat /output/entry.txt
```

The program writes exactly one line with no trailing newline, and asserts the text is 1–120 characters before writing.
